# ANIFLIX 🎌

> Hindi · Tamil · Telugu Anime — Free streaming via Telegram

A clean, fast landing page for the ANIFLIX anime community. Built with pure HTML/CSS/JS — no frameworks, no dependencies.

## 🚀 Deploy on Vercel

1. Upload this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your GitHub repo
4. Click **Deploy** — done!

## ✏️ Customize

Open `index.html` and replace:

```
https://t.me/YOUR_CHANNEL
```

With your actual Telegram channel link (appears 4 times in the file).
